# 12 — Product Design (draft)

Working name: **Wildfire Sentinel** (TBD)

## One-liner

NASA flags hundreds of heat sources over Japan every day; most are steel mills and factories. **Jev triages every one in milliseconds, raises an alert only for the ones that matter, and ai& turns each alert into a situation report** a municipal disaster officer can act on. Neo4j remembers every site and verdict, so the system gets cheaper and smarter every pass.

## Roles

| Layer | Tool | Role | Speed |
| --- | --- | --- | --- |
| Sentinel | **Jev** | Triage every hotspot from the GSI aerial photo; raise the alert | ~0.2 s / site; 71 sites in 5.6 s |
| Analyst | **ai&** (vision + text) | Detailed analysis of alerted sites only → structured situation report + brief (JA/EN) | ~5 s / report |
| Memory | **Neo4j Agent Memory** | Sites, verdicts (reasoning traces), detection history over time; skip known sites | instant |
| Context | Open-Meteo (weather), FIRMS (history), GSI (photo) | Facts the report is grounded on | — |

## Flow (user-confirmed: Jev raises the alert immediately, then fans out)

1. **FIRMS** → hotspots (live: last 1–2 days; replay: archive date).
2. **Memory check** (`search_locations_near`): known industrial site → filtered, no model call.
3. **Stage 1 — Jev sentinel** (one cheap request per hotspot, ~0.2 s): `industrial_nearby` (within ~400 m of center), `vegetation_nearby`, `houses_nearby`. **Possible fire → alert immediately** (shown on the map at once).
4. **Stage 2 — Jev deep probe** (only alerted sites; one request, many images, many questions in parallel, ~1 s):
   - Images: z16 mosaic (~1.8 km), z14 mosaic (~7 km context), satellite true color of the detection day.
   - Questions: fuel type, vegetation continuity toward houses, distance and **direction** of the nearest settlement, settlement size, terrain steepness, firebreaks (roads/rivers), water source for helicopters, smoke plume, cloud cover, industrial re-check.
5. **Composite scoring in code**: Jev answers + weather (Open-Meteo: wind speed/gusts/direction, humidity, days without rain) + FIRMS (FRP, detections, trend) → `danger`, `spread_risk`, `exposure` (wind blowing toward the settlement?), `urgency`. Weights live in code, tunable without re-running models.
6. **ai& analyst**: writes the situation report and the brief (JA/EN) from the structured findings + the wide aerial photo. Never invents numbers or times.
7. **Rules in code** bound the recommended actions (e.g. evacuation advice only if houses are within reach and danger ≥ 4).
8. **Neo4j Agent Memory** stores sites, every verdict as a reasoning trace, and the detection history.
9. Map UI: hotspots appear live colored by verdict; click → photos, probe answers, scores, memory trace, report.

## Situation report (ai& output, strict JSON) — draft fields

| Field | Type | Grounded on |
| --- | --- | --- |
| `headline_ja`, `headline_en` | string | all |
| `urgency` | 1–5 + reason | detection trend, FRP, time since first detection |
| `danger` (severity) | 1–5 + reason | FRP, land use, vegetation |
| `spread_risk` | low / moderate / high / extreme + reason | wind speed/gusts/direction, humidity, days without rain, terrain from photo |
| `exposure` | none / low / moderate / high + reason | houses nearby, distance to settlement, roads |
| `confidence` | low / medium / high | Jev confidence, cloud cover, number of detections |
| `key_evidence` | list | facts used |
| `unknowns` | list | what we can't tell from the data |
| `brief_ja`, `brief_en` | 3–4 lines | for the municipal officer |

Code adds: `recommended_actions` (rule-based), timestamps (never generated by the model).

## Demo modes

- **Live (today):** run over today's FIRMS data → shows the filtering (77% industrial, filtered in seconds).
- **Replay (Ofunato, 26 Feb – 1 Mar 2025):** FIRMS archive (`VIIRS_NOAA20_SP`, 103 detections) → Jev raises the alert on day 1 → ai& report with urgency rising day by day; memory shows the fire's history growing.

## Lessons from the spikes that shape the design

- Ask "**is there an industrial facility within ~400 m of the center**", not "what is at the exact center": VIIRS geolocation is ~375 m, so the center pixel often lands on water or forest next to a plant (Tokushima and Kitakyushu cases).
- Never let the model invent times; pass timestamps as facts.
- Escalate to ai& vision only when needed: Jev is ~20× faster.
